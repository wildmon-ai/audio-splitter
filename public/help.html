Audio Splitter — Help

Wildmon · Batch audio processing

What it does

Audio Splitter cuts samples out of long field recordings. For every audio file in the Source Folder (subfolders included), it extracts one 1-minute clip every N minutes and saves the clips in the Output Folder, keeping the same subfolder structure.

A clip is only made when a full minute of audio is left, so a recording never ends with a short or empty clip. Clips are mono and keep the file type of the original recording (and the bit depth of WAV and FLAC files). Supported files: WAV, FLAC, MP3, OGG, M4A and OPUS.

Quick start

  1. Choose the Source Folder with your recordings.
  2. Choose an empty Output Folder outside the Source Folder.
  3. Set Extract Every N Minutes.
  4. Click Start Processing and follow the progress bar and the log.

Settings

Extract Every N Minutes
Time between the start of one clip and the start of the next. With N = 10, a 60-minute recording gives 6 clips, starting at minutes 0, 10, 20, 30, 40 and 50. Use 1 or more.
Parallel Processes
How many clips are cut at the same time. 0 means automatic (one per CPU core). Use a lower number if the computer becomes slow, or if the recordings are on a USB drive or SD card.

Clip names

If the file name contains the recording start time as YYYYMMDD_HHMMSS, each clip is named with its own start time. With N = 10, SITE01_20240601_060000.wav gives SITE01_20240601_060000.wav, SITE01_20240601_061000.wav, SITE01_20240601_062000.wav, …

Otherwise, clips are named after their position in the recording, in minutes: recording_0000m.wav, recording_0010m.wav, …

Stopping and resuming

Cancel stops the job right away. A clip is only saved once it is complete, so stopping never leaves half-written clips behind.

Clips that already exist in the Output Folder are skipped and counted as "skipped" in the summary, so running again with the same folders continues where it stopped. Incomplete clips left by older versions are made again. To redo a clip yourself, delete it from the Output Folder first.

Tips

  • The Output Folder cannot be the Source Folder. If it is inside it, Audio Splitter leaves it out when looking for recordings.
  • Hidden files, the ._ files macOS leaves on memory cards and system folders are ignored. A folder that cannot be opened is skipped with a warning in the log.
  • If a file cannot be read, the error appears in the log and the other files keep going.
  • If two recordings overlap in time and would produce clips with the same name, only the first is kept and the log says so.
